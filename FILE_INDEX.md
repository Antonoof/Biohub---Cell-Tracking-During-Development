# File index

## Repository documentation

- `README.md` - public overview, workflow, component map, and navigation.
- `AUTHORS.md` and `CITATION.cff` - authorship and citation metadata.
- `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md` - source license,
  required attribution, and upstream-material boundaries.
- `docs/REPOSITORY_HISTORY.md` - main-branch material retained alongside this
  release.
- `CONTRIBUTING.md` - reproducibility and graph-safety requirements for changes.
- `TRAINING_AND_GRAPH_PROVENANCE.md` - exact training population and serving
  position of every component.
- `VALIDATION.md` - retained grouped-OOF, held-movie, replay, and hidden
  evidence.
- `docs/TRAINING_GUIDE.md` - canonical training commands.
- `docs/DATA_LAYOUT.md` - portable data and artifact layout.
- `docs/REPRODUCIBILITY_NOTES.md` - scope, limitations, and adaptation guidance.
- `docs/EXPERIMENTS.md` - completed experiment record at the reference release
  date.
- `docs/biohub_production_957_full_technical_architecture.pdf` - 25-page
  illustrated production architecture and component reference.
- `docs/PUBLICATION_CHECKLIST.md` - licensing, attribution, reproducibility,
  and release-readiness checks.
